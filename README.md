# 轻翻页 · PageTurner

**中文** · [English](README.en.md) · [日本語](README.ja.md)

极简的安卓自动翻页工具

看漫画、图集或长网页时，按设定间隔点击或滑动，手动触屏就暂停

对了，还有某些腾不出手的时候……你懂的

## 能做什么

- 定时翻页，可选择识别下一页按钮，或点击屏幕上的指定位置
- 自动向下浏览长页面，也可以滑到底后再翻页
- 小圆点轻点开始或暂停，长按展开，支持拖动
- 折叠屏支持，会记住点击位置和滑动幅度
- 连续两次没检测到页面变化时暂停，可关闭该项
- 完全免费、不用注册、没广告
- 支持中文、英文、日文，可在应用内切换
- 适合阅读，也适合暂时腾不出手的时候

## 怎么用

1. 下载 APK，在安卓手机上安装
2. 按应用提示开启「轻翻页」无障碍服务，不用再开悬浮窗权限
3. 选好间隔和翻页方式，点「显示圆点」
4. 打开阅读页面，长按圆点选位置，轻点圆点开始

你手动点按或滑动页面时会暂停，轻点圆点就能继续

## 语言

首次跟随手机的语言偏好，找不到匹配语言时显示英文

在右上角设置中选择「语言」，可切换简体中文、English、日本語，或恢复跟随系统

一个安装包包含三种语言，不需要按地区下载，也不读取 IP 或位置

## 使用前须知

需要 Android 8.0 或更新版本，阅读页面保持在前台

切换应用、锁屏、折叠或旋转屏幕时会暂停翻页

网页需要提供可读取的信息，才能判断页面底部或识别下一页；无法判断底部时按设置的滑动次数翻页

固定位置点击无法判断广告和网页弹层，手动触屏暂停也会受手机系统影响

不截屏，不联网，仅手动检查更新时会连接 GitHub
