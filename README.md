# 轻翻页 · PageTurner

极简的安卓自动翻页工具

看漫画、图集或长网页时，按设定间隔点击或滑动，手动触屏就暂停

## 能做什么

- 定时点击选好的翻页位置，间隔随时调整
- 自动向下浏览长页面，也可以滑到底后再翻页
- 小圆点轻点开始或暂停，长按展开，拖动挪位置
- 折叠前后分别记住点击位置和滑动幅度
- 连续两次没看到页面变化时暂停，也可以关闭这项检查
- 没有账号、广告或订阅

## 怎么用

1. 下载 APK，在安卓手机上安装
2. 按应用提示开启「轻翻页」无障碍服务，不用再开悬浮窗权限
3. 选好间隔和翻页方式，点「显示控制点」
4. 打开阅读页面，长按圆点选位置，轻点圆点开始

你手动点按或滑动页面时会暂停，轻点圆点就能继续

## 使用前知道这些

需要 Android 8.0 或更新版本，阅读页面保持在前台

切换应用、锁屏、折叠或旋转屏幕时会暂停，不会自己恢复

网页需要提供可读取的信息，才能判断底部或识别下一页；无法判断底部时按设置的滑动次数翻页

同一个网址也能换图片，因此会一起检查页面内容，有些图片变化读不到，误停时可在设置中关闭「无变化时暂停」

固定位置点击无法判断广告和网页弹层，手动触屏暂停也会受手机系统影响

不截屏，不保存或上传网页内容，只有手动检查更新时会连接 GitHub
