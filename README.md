# 轻翻页 · PageTurner

**中文** · [English](README.en.md) · [日本語](README.ja.md)

极简的自动翻页工具，支持安卓和电脑浏览器

看漫画、图集或长网页时，按设定间隔点击或滑动，手动触屏就暂停

对了，还有某些腾不出手的时候……你懂的

## 能做什么

- 定时翻页，可选识别下一页按钮，或点击屏幕上的指定位置
- 整页慢慢滑到底，或在页面中间停一停，到底后自动翻页
- 小圆点轻点开始或暂停，长按展开，支持拖动
- 折叠屏支持，会记住不同屏幕尺寸下的点击位置
- 连续两次没检测到页面变化时暂停，可关闭该项
- 完全免费、不用注册、没广告
- 支持中文、英文、日文，可在应用内切换
- 可仅看图片主体（帮你遮住广告），PC端可只看干净的图片阅读层，沉浸阅览
- 适合看本子（？）

## 怎么用

**安卓**

1. 下载 APK，在安卓手机上安装
2. 按应用提示开启「轻翻页」无障碍服务，不用再开悬浮窗权限
3. 选好间隔和翻页方式，点「显示圆点」
4. 打开阅读页面，长按圆点选位置，轻点圆点开始

触碰屏幕暂停，点击圆点继续

慢滑可选「一次滑到底」或「滑到一半停，再滑到底」，每段用时可设为 1–30 秒，大号数字控制每段之间和翻页前的停顿

右上角设置可开启「聚焦主体」，运行时遮住主体图片以外的内容，暂停后恢复，识别不到就保留原网页

**电脑 Chrome／Edge**

解压电脑扩展，在浏览器扩展管理页开启「开发者模式」，点「加载已解压的扩展程序」选择解压目录

打开漫画网页，点轻翻页扩展图标再开始；默认只看主体，选错时可手动选图片或下一页按钮，[详细说明](desktop/README.md)

## 语言

首次跟随手机的语言偏好，找不到匹配语言时显示英文

在右上角设置中选择「语言」，可切换简体中文、English、日本語，或恢复跟随系统

一个安装包包含三种语言，不需要按地区下载，不读取 IP 或位置

## 使用前须知

需要 Android 8.0 或更新版本，阅读页面保持在前台

切换应用、锁屏、折叠或旋转屏幕时会暂停翻页

「一半」按页面从顶部到底部的可滚动距离计算，不是半个屏幕；网页需要提供滚动信息，才能定位一半的位置，用时会受页面加载和系统影响

读不到页面长度时可用「一次滑到底」尝试，仍无法确认底部则暂停，不会一直空滑或按次数猜测翻页

固定位置点击无法判断广告和网页弹层，手动触屏暂停也会受手机系统影响

安卓不截屏，阅读期间不联网，仅手动检查更新时连接 GitHub；电脑阅读层显示原站图片，不上传阅读内容，原网页仍可能加载广告和运行脚本
