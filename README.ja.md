# ページめくり · PageTurner

[中文](README.md) · [English](README.en.md) · **日本語**

シンプルなAndroid向け自動ページめくりツール

漫画や画像ギャラリー、長いWebページを、設定した間隔でタップ・スクロールして読み進めます
画面に触れると一時停止します

そうそう、ちょっと手が離せないときにも……わかるよね

**[APKをダウンロード](https://github.com/BsTso/page-turner-releases/releases/latest)** · [不具合を報告](https://github.com/BsTso/page-turner-releases/issues) · [自分でビルド](BUILDING.md#build-on-windows)

## できること

- 次ページのボタンを検出するか、指定した位置をタップして、一定の間隔でページをめくります
- 長いページを下へスクロールし、一番下に着いてからめくることもできます
- 丸ボタンはタップで開始・一時停止、長押しでメニュー、ドラッグで移動できます
- 折りたたみ前後の画面サイズごとに、タップ位置とスクロール幅を記憶します
- 2回続けてページの変化を確認できないと一時停止します、この確認はオフにもできます
- 完全無料、登録不要、広告なし
- 中国語・英語・日本語に対応し、アプリ内で切り替えられます
- 読書はもちろん、ちょっと手が離せないときにも

## 使い方

1. APKをダウンロードしてAndroid端末にインストール
2. アプリの案内に従い「ページめくり」のユーザー補助をオンにします、別途オーバーレイの許可は不要です
3. 間隔とめくり方を選び「丸ボタンを表示」をタップ
4. 読むページを開き、丸ボタンを長押しして位置を選んだら、丸ボタンをタップして開始

手動でページをタップ・スクロールすると一時停止し、丸ボタンをタップすると再開します

## 言語

初回は端末の言語設定に合わせ、対応する言語がない場合は英語で表示します

右上の設定から「言語」を開くと、简体中文・English・日本語・端末の設定に合わせる、を選べます

1つのAPKに3言語が入っています、地域別のダウンロードやIPアドレス・位置情報の確認は不要です

## 使う前に

Android 8.0以降が必要です、読むページは前面に表示してください

アプリの切り替え、画面ロック、端末の折りたたみや回転で、ページめくりを一時停止します

下端や次ページのボタンを検出するには、ページが読み取り可能なユーザー補助情報を提供している必要があります
下端を判定できない場合は、設定した回数だけスクロールしてからめくります

位置指定のタップでは広告やページ内のポップアップを区別できません
画面に触れたときの一時停止も、端末によって動作が異なる場合があります

読書中はスクリーンショットを撮らず、通信もしません、手動で更新を確認するときだけGitHubに接続します
