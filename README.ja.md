# ページめくり · PageTurner

[中文](README.md) · [English](README.en.md) · **日本語**

AndroidとPCブラウザ向けのシンプルな自動ページめくりツール

漫画や画像ギャラリー、長いWebページを、設定した間隔でタップ・スクロールして読み進めます
画面に触れると一時停止します

そうそう、ちょっと手が離せないときにも……わかるよね

**[Android版](https://github.com/BsTso/page-turner-releases/releases/latest)** · **[PC拡張機能](https://github.com/BsTso/page-turner-releases/releases/latest/download/PageTurner-PC.zip)** · [不具合を報告](https://github.com/BsTso/page-turner-releases/issues) · [自分でビルド](BUILDING.md#build-on-windows)

## できること

- 次ページのボタンを検出するか、指定した位置をタップして、一定の間隔でページをめくります
- ページ全体をゆっくりスクロール、半分で休むこともでき、一番下に着いてからページをめくれます
- 丸ボタンはタップで開始・一時停止、長押しでメニュー、ドラッグで移動できます
- 折りたたみ前後の画面サイズごとに、タップ位置を記憶します
- 2回続けてページの変化を確認できないと一時停止します、この確認はオフにもできます
- 完全無料、登録不要、広告なし
- 中国語・英語・日本語に対応し、アプリ内で切り替えられます
- Androidは漫画の周りを隠し、PC版は画像だけの読みやすい表示にできます、一時停止で元に戻ります
- 読書はもちろん、ちょっと手が離せないときにも

## 使い方

**Android**

1. APKをダウンロードしてAndroid端末にインストール
2. アプリの案内に従い「ページめくり」のユーザー補助をオンにします、別途オーバーレイの許可は不要です
3. 間隔とめくり方を選び「丸ボタンを表示」をタップ
4. 読むページを開き、丸ボタンを長押しして位置を選んだら、丸ボタンをタップして開始

手動でページをタップ・スクロールすると一時停止し、丸ボタンをタップすると再開します

「一番下まで一度に」か「半分で休んでから、一番下まで」を選び、1段階の時間を1〜30秒に設定できます、大きな数字は途中とページをめくる前の待ち時間です

設定の「画像に集中」で実行中に漫画の周りを隠せます、一時停止で元に戻り、画像を認識できない場合はそのまま表示します、広告ブロック機能ではありません

**PCのChrome・Edge**

PC版ZIPを解凍し、拡張機能の管理画面でデベロッパーモードをオンにして、解凍した拡張機能を読み込みます

漫画のページで拡張機能を開いて開始します、初期設定は画像のみの表示で、画像や次ページのボタンは手動で選ぶこともできます、[詳しい説明](desktop/README.ja.md)

## 言語

初回は端末の言語設定に合わせ、対応する言語がない場合は英語で表示します

右上の設定から「言語」を開くと、简体中文・English・日本語・端末の設定に合わせる、を選べます

1つのAPKに3言語が入っています、地域別のダウンロードやIPアドレス・位置情報の確認は不要です

## 使う前に

Android 8.0以降が必要です、読むページは前面に表示してください

アプリの切り替え、画面ロック、端末の折りたたみや回転で、ページめくりを一時停止します

「半分」は画面の半分ではなく、ページの上端から下端までスクロールできる距離の半分です、位置の計算にはページのスクロール情報が必要で、実際の時間は読み込みや端末によって変わります

ページの長さを取得できない場合は「一番下まで一度に」を試せます、それでも下端を確認できない場合は、空のスクロールを繰り返したり回数だけでめくったりせず一時停止します

位置指定のタップでは広告やページ内のポップアップを区別できません
画面に触れたときの一時停止も、端末によって動作が異なる場合があります

Androidは読書中にスクリーンショットや通信を使わず、手動の更新確認でのみGitHubに接続します、PC版は元のサイトの画像を表示し内容を送信しませんが、元のページの広告やスクリプトは動作する場合があります
