# 轻翻页 · 电脑浏览器扩展

**中文** · [English](README.en.md) · [日本語](README.ja.md)

在 Chrome 或 Edge 中阅读漫画，开始后只看主体图片，暂停时恢复网页

## 安装

1. 下载 `PageTurner-PC.zip`，解压到一个固定文件夹
2. 打开 `chrome://extensions`（Edge 用 `edge://extensions`），开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹

在浏览器工具栏的扩展菜单中固定轻翻页，以后点图标就能打开

## 使用

打开漫画网页，点轻翻页图标，选择间隔和翻页方式，再点「开始」

- 大号数字控制停顿，慢滑可选整页或分两段，每段 1–30 秒
- 「只看主体」开启后显示干净的图片阅读层，关闭后直接滚动原网页
- 新一页从顶部开始，暂停再继续保留阅读位置
- 慢滑逐渐起步和收尾，中段匀速；主体没加载好时等待，找不到时暂停
- 圆点轻微呼吸表示运行中，静止表示暂停，鼠标移上去可看剩余秒数
- 点击、滚轮、按键或切换标签页会暂停，圆点可以继续，× 关闭控制层
- 自动选择不对时，点右上角的点，在「选主体图片」或「选下一页按钮」中重新选择
- 每次阅读最多 30 分钟，暂停后可手动继续
- 支持中文、英文、日文，首次跟随浏览器语言

## 边界

这是阅读层，不是广告拦截器，原网页的脚本和请求仍可能运行

适合图片式漫画网页，不支持浏览器设置页、内置 PDF 阅读器或其他桌面软件；跨域 iframe、Canvas 和特殊翻页控件可能无法识别

同一网站由工具触发的翻页可继续，手动跳转或跳到其他网站后需要重新开始，登录和验证码需要你亲自处理

一半按阅读内容可滚动的距离计算，网页加载和窗口大小会影响实际位置

本地保存设置，阅读会话和临时选择只在浏览器会话内使用，不上传阅读内容，不读取 Cookie，不调用远程 AI

当前是解压安装版，更新时下载新版、替换文件夹内容，再到扩展管理页点刷新，并刷新正在阅读的网页，不会通过商店自动更新
