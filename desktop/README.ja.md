# ページめくり · PCブラウザ拡張機能

[中文](README.md) · [English](README.en.md) · **日本語**

Chrome・Edgeで漫画の画像だけを表示し、一時停止すると元のページに戻ります

## インストール

1. `PageTurner-PC.zip`をダウンロードし、移動しないフォルダに解凍します
2. `chrome://extensions`または`edge://extensions`を開き、デベロッパーモードをオンにします
3. 「パッケージ化されていない拡張機能を読み込む」から`manifest.json`のあるフォルダを選びます

拡張機能メニューでページめくりを固定すると便利です

## 使い方

漫画のページで拡張機能のアイコンを押し、設定して「開始」を選びます

- 大きな数字は待ち時間、スクロールは一度に全部か半分で休むかを選び、1段階を1〜30秒に設定できます
- 「画像だけ表示」をオフにすると、元のページをスクロールします
- 次のページは先頭から表示し、一時停止からの再開では読んでいた位置を保ちます
- 点がゆっくり膨らんだり縮んだりしている間は動作中、静止していれば一時停止中です、マウスを重ねると残り秒数が見えます
- クリック・ホイール・キー入力・タブの切り替えで停止、丸ボタンで再開、×で操作表示を閉じます
- 自動選択が違う場合は右上の点から画像や次ページのボタンを選び直せます
- 1回の実行は30分まで、手動で再開できます
- 中国語・英語・日本語に対応、初回はブラウザの言語に合わせます

## 対応範囲

広告ブロッカーではなく閲覧用の表示です、元のページのスクリプトや通信は動作することがあります

画像形式の漫画ページ向けです、ブラウザの設定画面・内蔵PDFビューア・他のPCアプリには対応せず、別ドメインのフレーム・Canvas・特殊な操作部品は認識できない場合があります

ツールによる同じサイト内のページめくりは継続できます、手動の移動や別サイトでは再開操作が必要で、ログインや認証は自分で行います

半分の位置は読める内容のスクロール可能な距離で計算し、読み込みやウィンドウサイズで変わります

設定はローカル保存、閲覧中の状態と選択は一時的に使用し、内容の送信・Cookieの取得・外部AIの利用はありません

解凍して読み込む版なので、新版のファイルに置き換え、拡張機能と閲覧中のページを再読み込みしてください、ストアによる自動更新はありません
